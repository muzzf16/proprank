# PropRank

Property SEO Intelligence Platform built for Codex.

## Vision

PropRank helps property developers, agencies, and SEO consultants improve visibility across Google Search, Google Maps, Google Business Profile, and AI Search.

## MVP Modules

- Technical SEO Agent
- Local SEO Agent
- GEO Agent
- Schema Agent
- Property Visibility Score (PVS)
- Google Search Console Integration

## Planned Stack

- FastAPI
- PostgreSQL
- Redis
- Next.js
- OpenAI API
